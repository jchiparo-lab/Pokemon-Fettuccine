POKEMON FETTUCCINE VERSION - PLAYTEST 4
=======================================

Thanks for testing!


HOW TO PLAY
-----------
1. You need a clean US Pokemon Emerald ROM (not included).
   It should match:
     CRC32: 1F1C08FB
     SHA-1: f3ae088181bf583e55daf962a92bb46f4f1d07b7
2. Apply fettuccine-playtest-4.bps to it. Either of these works:
     - Rom Patcher JS (in your browser): https://www.marcrobledo.com/RomPatcher.js/
     - Floating IPS (Flips)
3. Play the patched ROM in mGBA or any GBA emulator.

Your Playtest 3 save keeps working: give the new ROM the same file
name as before (so the save file matches) or copy the .sav across.
Use an in-game save, not a save state from an older playtest.


NEW SINCE PLAYTEST 3
--------------------
- Faster HMs: CUT, ROCK SMASH, STRENGTH, SURF, WATERFALL and DIVE
  just ask "Use CUT?" (and so on). Say YES and it happens, with no
  extra messages.
- Fix for the "walking down forever" bug after catching a Pokemon.
  The game now recovers from it by itself.

New in Playtest 3, in case you missed it: Wonder Trade (right-hand
counter upstairs in every Pokemon Center), the National Pokedex from
the start, reusable TMs, no more trading to evolve, INSTANT text
speed, and WILDCARD'S CASTLE.


DEBUG MENU
----------
This build has the developer's debug menus turned on, so you can
skip ahead or set up a test:
  - Overworld: hold R and press START (mGBA keyboard: hold S, Enter)
  - In battle: press SELECT on the battle menu (mGBA: Backspace)
  - Sprite viewer: SELECT on a summary screen (mGBA: Backspace)
Use a separate save or a save state first, and say in your report
if that save used the debug menu.


AFTER-BATTLE GLITCHES
---------------------
If anything odd happens right after a battle (the player moving on
their own, buttons not working, a freeze, strange graphics), make a
SAVE STATE right away (mGBA: File > Save State) and send it in.
